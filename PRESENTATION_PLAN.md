# 📊 План Презентации - Document Detection System

## 🎯 Цель презентации
Продемонстрировать автоматизированную систему обнаружения и валидации документов с использованием компьютерного зрения и распознавания QR-кодов.

---

## ⏱️ Структура презентации (10-15 минут)

### 1. Вступление (2 минуты)
**Слайд 1: Титульный**
- Название проекта: "Intelligent Document Detection System"
- Armeta CV Hackathon 2024
- ФИО участника

**Слайд 2: Проблематика**
- ❌ Ручная проверка документов - медленно и дорого
- ❌ Человеческие ошибки при валидации
- ❌ Сложность массовой обработки
- ✅ **Решение:** Автоматизация с помощью AI

---

### 2. Техническое решение (3-4 минуты)

**Слайд 3: Архитектура системы**
```
┌─────────────┐
│   PDF/Image │
└──────┬──────┘
       │
┌──────▼──────────┐
│  YOLOv8s Model  │ ← 11.2M parameters
│  Detection      │    88.1% accuracy
└──────┬──────────┘
       │
┌──────▼──────────┐
│  QR Decoder     │ ← pyzbar
│  (99.5% acc)    │
└──────┬──────────┘
       │
┌──────▼──────────┐
│  Validator      │ ← Business rules
│  + HTML Report  │
└─────────────────┘
```

**Слайд 4: Детекция объектов**
- **YOLOv8s** - компактная модель (22 МБ)
- Обнаружение 3 классов:
  - 📝 **Подписи** - 77.6% точность
  - 🔖 **Печати** - 87.0% точность
  - 📱 **QR-коды** - 99.5% точность ⭐
- Скорость: ~50-100 мс на изображение

**Слайд 5: QR Декодирование**
- Автоматическое распознавание данных
- Извлечение контактов, ссылок, текста
- Оценка качества декодирования
- Форматирование результатов

### 4. Live Demo (3-4 минуты)

**Слайд 7: Демонстрация**

**Сценарий 1: Desktop обработка**
```bash
python enhanced_inference.py --pdf contract.pdf
```
- Показать процесс обработки PDF
- Открыть HTML отчет
- Продемонстрировать результаты валидации

**Сценарий 2: Mobile приложение**
```bash
streamlit run mobile_app.py
```
- Открыть на телефоне (через ngrok/локальную сеть)
- Сканировать документ через камеру
- Показать real-time детекцию
- Декодировать QR код

**Сценарий 3: Batch обработка**
```bash
python generate_submission.py --output results.json
```
- Обработка 13 тестовых PDF
- Показать submission.json
- Статистика обработки
