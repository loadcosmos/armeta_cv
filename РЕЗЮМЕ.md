## ❗ ВАЖНО: Про QR Детектор

### ✅ НЕ НУЖНО ПЕРЕОБУЧАТЬ!

**QR декодер (`qr_decoder.py`) - это НЕ модель машинного обучения!**

- Это обычная Python библиотека (`pyzbar`)
- Работает сразу после установки
- Просто читает содержимое QR кодов, которые уже обнаружены YOLO
- Никакого обучения не требуется!

### Что требует обучения:
- ✅ **Только YOLO модель** - УЖЕ обучена (файл `best.pt`)

### Что НЕ требует обучения:
- ✅ QR декодер (`qr_decoder.py`) - библиотека
- ✅ Валидатор (`validator.py`) - правила бизнес-логики
- ✅ HTML репортер (`html_reporter.py`) - генерация отчетов
- ✅ Мобильное приложение (`mobile_app.py`) - интерфейс

```
┌─────────────────────────────────────┐
│   PDF документ (например, contract) │
└──────────────┬──────────────────────┘
               ↓
┌──────────────────────────────────────┐
│ [1] YOLO Detection (best.pt)         │ ← ЕДИНСТВЕННАЯ ОБУЧЕННАЯ МОДЕЛЬ
│     - Детектирует QR/подписи/печати  │
└──────────────┬───────────────────────┘
               ↓
┌──────────────────────────────────────┐
│ [2] QR Decoding (pyzbar)             │ ← НЕ ML! Готовая библиотека
│     - Читает содержимое QR кодов     │
│     - URL, email, текст, телефон     │
└──────────────┬───────────────────────┘
               ↓
┌──────────────────────────────────────┐
│ [3] Validation (business rules)      │ ← НЕ ML! Правила бизнес-логики
│     - Контракт: 2+ подписи, печать   │
│     - Лицензия: печать + подпись     │

               ↓
┌──────────────────────────────────────┐
│ [4] HTML Report                      │ ← НЕ ML! Генерация HTML

               ↓
```

## ❓ Частые вопросы

### Q: Нужно ли переобучать модель для QR декодирования?
**A: НЕТ!** QR декодер - это не ML модель. Это библиотека `pyzbar`, которая просто читает содержимое QR кодов. Работает сразу после `pip install pyzbar`.

### Q: Нужно ли переобучать модель для валидации?
**A: НЕТ!** Валидатор - это просто правила (например: "контракт должен иметь 2+ подписи"). Никакого ML не требуется.

### Q: Нужно ли переобучать модель для HTML отчетов?
**A: НЕТ!** HTML репортер - это просто генерация HTML файлов. Никакого ML не требуется.

### Q: Что вообще нужно обучать?
**A: Только YOLO модель - и она УЖЕ обучена!** Файл `best.pt` на Kaggle - это готовая модель.

### Q: Структура проекта изменена на kaggle/local/?
**A: НЕТ!** Текущая структура - плоская (все файлы в корне). Это та структура, которую я создал. Если кто-то предложил другую структуру - это не я.

### Q: Можно ли использовать систему сейчас?
**A: ДА!** Просто:
1. Скачайте `best.pt` с Kaggle
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите: `python enhanced_inference.py --input file.pdf --html`

### Q: Что делать, если хочу изменить правила валидации?
**A:** Откройте `validator.py` и измените правила в классе `ContractValidator` или `LicenseValidator`. Это обычный Python код, никакого обучения не нужно!
